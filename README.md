This project shows how to set up a simple CI/CD pipeline. It includes:
- Automated tests
- Code checks
- Builds
- Deployments to cloud services

## Part 1: Continuous Integration
- Uses a pipeline to automatically run tests and code checks on every push or pull request.
- Ensures code is always in good shape before merging.

## Part 2: Continuous Deployment
- Deploys the app to Azure once the code is merged.
- Helps deliver new features quickly and reliably.
